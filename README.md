# 📊 Sales Compass

> Стратегический аналитический дашборд для руководства компании.  
> Позволяет CEO, администраторам и менеджерам видеть полную картину бизнеса в одном месте: финансы, продажи, маркетинг и разработку.

**Версия:** 2.1 · **Статус:** ✅ MVP готов · **Данные:** Mock (Bitrix24 API — в планах)

---

## 👥 Роли и доступ

| Роль | Что видит | Разделы |
|------|-----------|---------|
| 👑 **CEO** | Всё: все отделы, все данные, полная аналитика | 5 вкладок |
| 🛡️ **Администратор** | Финансы, продажи, маркетинг + управление пользователями | 3 вкладки |
| 👤 **Менеджер** | Только свои сделки, отчёты по своему региону | 2 вкладки |

Защита реализована на уровне роутов — при попытке зайти в недоступный раздел происходит редирект на главную.

## 📱 Страницы

### 🔐 Авторизация `/auth`
- Форма входа (email + пароль)
- Быстрый демо-вход для CEO, Админа, Менеджера
- Split-layout с описанием возможностей системы

---

### 🏠 Главный дашборд `/`

Разбит на **5 вкладок**:

#### 1 — Executive Summary
| Блок | Описание |
|------|----------|
| **KPI-карточки × 4** | Выручка, сделки, средний чек, маржинальность — с динамикой к прошлому периоду |
| **Воронка продаж** | Этапы от лидов до закрытия, конверсия между шагами |
| **Проекты разработки** | Статусы всех активных IT-проектов |

#### 2 — Финансы
| Блок | Описание |
|------|----------|
| **График план / факт** | 12 месяцев: столбцы плана vs факта, зелёный = перевыполнение |
| **Процент выполнения** | Пилюля-бейдж с общим % по периоду |

#### 3 — Продажи
| Блок | Описание |
|------|----------|
| **Топ менеджеров** | Рейтинг по выручке, медальки, прогресс-бары, цикл сделки |
| **Воронка продаж** | Конверсия на каждом этапе |
| **Зависшие сделки** | Сделки без активности более 15 дней |

#### 4 — Маркетинг
| Блок | Описание |
|------|----------|
| **ROI по каналам** | Google Ads, Facebook, SEO, Email, Партнёры, Холодные звонки |
| **Таблица** | Лиды, расходы, выручка, ROI%, конверсия, стоимость лида, тир (Топ/Хор./Сред./Низк.) |

ROI рассчитывается по формуле: `(Выручка − Расходы) / Расходы × 100%`

#### 5 — Разработка
| Блок | Описание |
|------|----------|
| **Сводка статусов** | Активные / завершённые / просроченные / под риском |
| **Список проектов** | Дедлайн, загрузка команды, индикатор превышения бюджета |

---

### 🏢 Отделы `/departments`
- Доступно: CEO, Администратор
- Детализация показателей по структурным единицам компании

### 📊 Отчёты `/reports`
- Доступно: все авторизованные пользователи
- Финансовые отчёты по месяцам, тренды, динамика
- Экспорт в **Excel** и **PDF**

### 💰 Зарплаты `/salaries`
- Доступно: CEO, Администратор
- Базовая ставка + автоматический расчёт бонусов по выполнению плана

## ⚠️ Обработка ошибок

| Ситуация | Реакция системы |
|----------|----------------|
| Нет данных за период | Пустое состояние с подсказкой |
| Ошибка источника данных | `ErrorCard` с описанием |
| Несуществующий URL | Страница 404 с кнопкой возврата |
| Нет доступа по роли | Редирект на `/` |

## 💡 Заметки

- Сессия хранится в `localStorage` → ключ `sales_compass_session`
- Предустановки фильтров → ключ `sales_compass_filter_presets`
- При обновлении страницы данные и сессия восстанавливаются автоматически
- TypeScript strict mode включён — все компоненты полностью типизированы
