# 🧪 Способы симуляции ошибок загрузки данных

## 1️⃣ Способ 1: Использование флага SIMULATE_DATA_ERROR (⭐ РЕКОМЕНДУЕТСЯ)

**Файл:** `src/data/mockData.ts`

Найдите строку:
```typescript
export const SIMULATE_DATA_ERROR = false;
```

Измените на:
```typescript
export const SIMULATE_DATA_ERROR = true;
```

Это сразу покажет экран ошибки когда вы загрузите страницу.

---

## 2️⃣ Способ 2: Очистить массив продуктов в консоли браузера

Откройте DevTools (F12) и в консоли выполните:
```javascript
// Это очистит все продукты и покажет пустой список
localStorage.clear()
location.reload()
```

---

## 3️⃣ Способ 3: Условно возвращать ошибку в handleRefresh

Временно измените функцию в `src/pages/Index.tsx`:
```typescript
const handleRefresh = useCallback(() => {
  setDataError('Тестовая ошибка при обновлении данных');
}, []);
```

Затем нажмите кнопку "Обновить" на панели фильтров.

---

## 4️⃣ Способ 4: Отключить JavaScript для всех запросов в Network

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Network"
3. Найдите запросы и посмотрите, как приложение обрабатывает отсутствие данных

---

## 5️⃣ Способ 5: Использовать DevTools для имитации сетевых ошибок

1. Откройте DevTools (F12)
2. Перейдите на вкладку "Network"
3. В левом углу найдите выпадающее меню с типами сети
4. Выберите "Offline" для полного отключения интернета
5. Перезагрузите страницу

---

## 🎯 Что вы увидите при ошибке:

✅ Красивый экран ошибки с иконкой
✅ Сообщение об ошибке
✅ Кнопки "Попробовать снова" и "На главную"
✅ Информационный блок с подсказкой

---

## 🔄 Как вернуть нормальное состояние:

Просто измените флаг обратно:
```typescript
export const SIMULATE_DATA_ERROR = false;
```

И перезагрузите страницу!
